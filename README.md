# 나의 할 일 목록

브라우저에서 바로 쓰는 할 일 목록 앱입니다. 프레임워크나 빌드 도구 없이 순수 HTML, CSS, JavaScript로 만들었습니다.

## 주요 기능

- **할 일 추가**: 입력창에 내용을 쓰고 "추가" 버튼을 누르거나 Enter 키를 누릅니다.
  - 빈 내용이나 이미 등록된 내용은 추가되지 않고 알림이 뜹니다.
- **완료 표시**: 체크박스를 누르면 완료/미완료가 바뀝니다.
- **삭제**: 항목 오른쪽의 × 버튼으로 하나씩 지웁니다.
- **완료된 항목 삭제**: 완료한 항목을 한 번에 지웁니다. 완료한 항목이 없으면 버튼이 비활성화됩니다.
- **필터**: 전체 / 진행중 / 완료 중 원하는 항목만 골라 봅니다.
- **개수 표시**: 전체 할 일과 완료한 할 일의 개수를 보여 줍니다.
- **자동 저장**: 할 일은 브라우저의 LocalStorage에 저장되어, 페이지를 닫았다 다시 열어도 남아 있습니다.

## 실행 방법

설치할 것이 없습니다. 저장소를 내려받은 뒤 `index.html`을 브라우저로 열면 됩니다.

```bash
git clone https://github.com/D-hyunny/My-ToDo-App.git
cd My-ToDo-App
```

그다음 `index.html` 파일을 더블클릭하거나 브라우저 창으로 끌어다 놓습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조 (입력창, 필터, 목록) |
| `style.css` | 화면 디자인 |
| `main.js` | 추가, 완료, 삭제, 필터, 저장 동작 |

## 참고

- 할 일은 사용하는 브라우저에만 저장됩니다. 다른 브라우저나 다른 컴퓨터에서는 보이지 않고, 브라우저의 사이트 데이터를 지우면 함께 사라집니다.
- 선택한 필터는 저장하지 않으므로, 새로고침하면 "전체"로 돌아갑니다.
